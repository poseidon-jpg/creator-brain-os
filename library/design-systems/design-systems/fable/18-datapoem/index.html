Studio statement

We don't draw pictures. We write systems that draw. Each work is an algorithm — a few hundred lines of deliberate code — seeded with a number and released onto the canvas. The same system never breathes the same way twice. That's the poem part.

Founded in 2019 by Mara Okonjo and Deniz Aral, DATAPOEM operates from a former letterpress workshop in Rotterdam. We make long-form generative series, live algorithmic installations, and commissioned systems for institutions that want art with a pulse.

Why code

A photograph is a moment kept. A painting is a moment made. A system is every possible moment, waiting for a seed.

01 / CONSTRAINT

One palette, forever

Ink black, paper white, signal orange. Three colours since 2019. Constraint is the studio's oldest algorithm.

02 / HONESTY

Ship the source

Every collector receives the full annotated source code of their piece, printed and bound. The art is the instructions.

03 / CHANCE

Respect the seed

We never cherry-pick outputs. The seed chooses. If the system produces something ugly, the system needed to be better.

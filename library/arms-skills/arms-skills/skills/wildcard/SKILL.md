# Wildcard

One rule: **keep the look and the voice, change the shape.**

The surprise is the structure. The voice and the colours are how people know the work is the user's, so those never move.

The colour palette sticks on every wildcard, no exceptions: a page, a slide, a design, or one surprise scene in a video. A surprise look (a risograph print, a blueprint, a departure board, a toy) is re-coloured in the palette the work already uses, never its own colours. Real brand logos shown inside it keep their own colours.

## Writing

Keep:
- The user's tone of voice, word level and energy. If a `tone` skill is installed, follow it.
- Any fixed rule from their tone, such as a sign-off they always use.
- The facts. Nothing new gets claimed.

Change the structure. Pick a shape the other versions don't use:
- Where the list sits, or no list at all.
- Bullets, labelled paragraphs, numbered steps, questions with answers, or one short story.
- What opens the piece and what closes it.
- The order of the beats: payoff first, steps first, or example first.
- Stock phrases that drifted into every version by habit (the link line, a sign-off that isn't fixed, the P.S.). The voice stays; the habitual wording changes. A phrase the user's tone makes fixed stays.

Change enough that the versions look different at a glance. If the wildcard reads like the others with the list moved, it failed.

## Design

Keep:
- The same colour palette, fonts and style the work already uses.

Change the structure:
- Layout, grid, order of blocks, what is big and what is small, where the eye lands first.

## How to use it

1. Look at the other versions (or the one the user is looking at). Name each one's structure in one line.
2. Pick a structure none of them use.
3. Build it in the same voice or palette. Facts stay true to the source.
4. Label it **Wildcard** and say in one line what structure you swapped.

When you write three versions for the user to pick from, the third one is the wildcard. If the other two must reuse something fixed (a set headline, a set opening line), the wildcard is the one allowed to break that too.

## Don't

- Change the tone to be "different". Voice is what stays.
- Change the palette to be "different". Same colours.
- Turn it into a long explanation. One build, one line on what changed.

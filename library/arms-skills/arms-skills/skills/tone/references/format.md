# Format - how each channel displays text

Tone is how you sound. Format is how a channel shows the text. Keep them apart, because the same voice looks different on a phone feed, an email and a chat app.

The platform facts below are general and change from time to time. If a draft depends on an exact number, check the platform's current help page. Your own taste per channel goes under "Your channel rules" at the bottom.

## Every channel

- When a character cap applies, count it, don't eyeball it. Show the count next to each option, like `Your headline here (17)`.
- Markdown (`**bold**`, `# heading`) only works where the channel renders it. Everywhere else the asterisks show as typed.
- Lead with the point. Most feeds cut the text after a line or two and hide the rest behind "more".

## Plain-text platforms (many community forums, comment boxes)

- No markdown. Bold needs the platform's own editor, or Unicode bold letters (𝗯𝗼𝗹𝗱) as a workaround. Use those lightly, because screen readers read them badly.
- Short paragraphs with blank lines between them read best in a narrow column.

## YouTube

- Title cap: 100 characters. Most of it gets cut on phones, so the first 50 or so do the work.
- Description cap: 5,000 characters. Keep `https://` on every link so it is clickable.

## X

- 280 characters per post on a standard account. Line breaks show as typed.

## LinkedIn

- Post cap: 3,000 characters. The feed cuts the post after roughly the first three lines, so the hook has to land there.

## Threads

- 500 characters per post. Put extra detail in a reply under the post.

## Instagram

- Caption cap: 2,200 characters. Only the first line or so shows before "more".
- Links in captions are not clickable, so a link goes in a DM, a bio link or a story.

## TikTok

- Captions show only a line or two before "more", so the point goes first.
- Some scheduling tools strip line breaks from TikTok captions. If yours does, write the caption as flowing sentences instead of a list.

## Email newsletters

- Embedded videos don't play in most email apps. Use the video's thumbnail as an image that links to the video.
- Paste formatted text (rich text or HTML), not markdown, or the asterisks show up in the email.
- Subject line plus preview text: write both, because the preview line shows in the inbox next to the subject.

## Chat apps (Telegram, WhatsApp, Slack and similar)

- Tables don't read well on a phone. Use short labelled lines instead (`Status: done`).
- Lead with the result, then the details. Keep paragraphs to one or two lines.

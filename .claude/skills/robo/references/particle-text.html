/robo reference - interactive effect

Particle TYPOGRAPHY

Text sampled into a few thousand square dots. Each dot springs back to its letter. The mouse shoves them aside with momentum. Move your cursor through the words below.

Dark stage - cream dots, orange flecks

Default hero treatment. Phrases cycle every ~5s. Type your own line and hit SET.

black · cream · orange 7%

Paper stage - ink dots

Same engine on the light background. Ink dots, same orange fraction.

paper · ink · orange 7%

The engine - copy this block

One function, self-contained. Call particleText(canvas, opts); it returns { setText, destroy }. Respects prefers-reduced-motion (renders the text once, static).







  
Options

  

    
OptionDefaultWhat it does

    
phrases['ROBO']Lines to cycle through. One entry = no cycling.

    
cycleMs5200Time per phrase. 0 disables cycling.

    
dot'#e8e2d2'Base dot colour. Paper bg → ink #1c1a16.

    
accent / accentFrac'#ff6b1a' / 0.07Orange fleck colour and fraction. Keep the fraction small - orange discipline applies.

    
bg'#131311'Frame clear colour. Use 'transparent' to sit over another background (clearRect instead of fill).

    
font'600 FSpx Outfit'Sampling font. Outfit 600 fills well; Doto 900 gives a sparse double-dotted look.

    
maxParticles3200 (1900 mobile)Dot budget. More = denser letters, more CPU.

    
mouseR110Repulsion radius in px.
